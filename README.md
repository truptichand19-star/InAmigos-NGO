# InAmigos NGO Website

This project is a simple NGO awareness website created using HTML and CSS.

## About the Project

The website provides information about InAmigos NGO and its initiatives.

## Technologies Used

- HTML
- CSS

## Features

- NGO information
- Project/initiative details
- Simple and responsive design
- Images and visual content
